¿Qué es Rocketbot Xperience?

Formularios no-code inteligentes
Capturan datos estructurados con lógica condicional y permisos avanzados sin escribir código.
Disparan flujos automatizados
Al enviar un formulario se activa automáticamente un robot RPA o una API para procesar los datos.
Control de acceso granular
Formularios públicos o privados con autenticación, roles y permisos por usuario o grupo.
Seguimiento desde el Orquestador
Monitorea cada envío y su ejecución desde la consola de Rocketbot con logs completos.

Cómo Funciona

1
Diseño de formulario
Arrastra y suelta campos: texto, fechas, desplegables, checkboxes y más con lógica condicional.
2
Configuración del disparador
Define qué robot o API se activa automáticamente al recibir un envío del formulario.
3
Envío + ejecución automática
El usuario completa el formulario y el flujo automatizado se ejecuta de inmediato en segundo plano.
4
Seguimiento y logs
Monitorea el estado desde Rocketbot Orchestrator con trazabilidad completa de cada ejecución.

FAQ

Preguntas Frecuentes

¿Para qué sirve Xperience?
Permite a los usuarios entregar información directamente a los robots, completar formularios para iniciar procesos, validar datos o proporcionar aprobaciones manuales en flujos de automatización.
¿Necesito saber programar para usar Xperience?
No. Xperience fue diseñado para que cualquier persona pueda crear formularios fácilmente a través de una interfaz visual e intuitiva, sin necesidad de conocimientos técnicos.
¿Qué tipos de campos puedo incluir en los formularios?
Texto, desplegables, casillas de verificación, botones, fechas y más, todos personalizables con lógica condicional para mostrar u ocultar campos según las respuestas del usuario.
¿Xperience funciona con bots desatendidos?
No directamente; Xperience fue diseñado para procesos atendidos que requieren participación activa del usuario como punto de entrada al flujo automatizado.
¿Dónde se muestran los formularios?
Son accesibles mediante URL del navegador en Chrome, Edge, Firefox, etc. Pueden configurarse como públicos o privados con autenticación según las necesidades de seguridad.
¿Puedo integrar Xperience con otros sistemas?
Sí, usando los conectores de Rocketbot Studio para integrar datos del formulario con procesos automatizados y sistemas externos mediante API.
¿Qué beneficios tiene usar Xperience?
Mejora la interacción humano-bot; reduce errores de entrada de datos manual; acelera procesos que requieren intervención humana; facilita la adopción de RPA en áreas no técnicas de la organización.
