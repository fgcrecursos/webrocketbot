FAQ

Preguntas frecuentes

Es una herramienta central para administrar, programar y monitorear la ejecución de bots desde un solo lugar. Permite gestionar múltiples robots, programar tareas, monitorear logs, distribuir cargas de trabajo y manejar robots tanto de Python como de Rocketbot Studio.
Sí. El Orquestador te permite ver el estado en tiempo real de todos tus bots, asignar tareas dinámicamente, acceder a métricas y logs detallados, y escalar operaciones manteniendo el control total desde una sola consola.
Podés asignar bots a flujos de trabajo, programar ejecuciones automáticas o manuales, configurar condiciones por fecha y hora, supervisar el avance paso a paso y gestionar versiones de tus robots sin interrumpir los procesos en producción.
El Orquestador soporta robots Rocketbot Studio (.db) y robots personalizados (.zip con Python, Node.js o CMD). Podés editar, reemplazar versiones y reutilizar los mismos robots en distintos entornos (desarrollo, QA, producción).
No. La interfaz es visual e intuitiva: usuarios sin perfil técnico pueden programar y monitorear bots con pocos clics. Los equipos técnicos pueden además aprovechar funciones avanzadas como API REST, webhooks y configuración de entornos.
Incluye autenticación con control de roles (RBAC), 2FA (autenticación de dos pasos), HTTPS con certificados SSL, encriptación de credenciales con APIKEY y registros completos de actividad de usuarios y bots para auditoría.
Sí. El Orquestador ofrece una API REST robusta para conectar ERPs, CRMs, bases de datos, plataformas web y servicios cloud. Además, enviá notificaciones vía webhooks al inicio o finalización de cada ejecución.
Rocketbot Xperience es una funcionalidad del Orquestador que permite crear interfaces visuales (formularios web) conectadas directamente con los procesos automatizados. Permite que usuarios completen datos, seleccionen opciones o aprueben acciones antes de que el robot continúe.
Contás con centro de ayuda y documentación oficial, canal técnico vía Slack para clientes con licencia, comunidad activa en el foro oficial y sesiones de onboarding incluidas según tu plan contratado.
