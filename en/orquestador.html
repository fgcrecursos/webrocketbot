Security and resilience you can operate on

The Orchestrator runs on AWS infrastructure with a microservices architecture, layered security, and high availability, keeping your operations secure, available, and under control.

Security and access

  • Role-based access control (RBAC)
  • Single sign-on (SSO)
  • Two-factor authentication (2FA)
  • Encrypted HTTPS / TLS 1.2 communication
  • Sessions protected with JWT
  • Passwords hashed with Argon2 and bcrypt

Platform protection

  • Web Application Firewall (WAF) and layered defense
  • Intrusion detection and prevention
  • Amazon GuardDuty and AWS Security Hub
  • Robots encrypted at rest (Amazon S3)
  • Public access restricted on critical components
  • Regular ethical hacking and vulnerability management

Continuity and resilience

  • Multi-Availability Zone AWS infrastructure
  • High-availability Multi-AZ database
  • Continuous monitoring with Amazon CloudWatch
  • Auto-scaling based on demand
  • Backups with retention and restore testing
  • Central repository with versioning and rollback
